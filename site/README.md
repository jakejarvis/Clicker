# clicker.jarv.is

The download page for Clicker, built with [Astro](https://astro.build) and deployed to Vercel from this directory. How it works, from the release data to the homepage shot, is in [docs/site.md](../docs/site.md).

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # writes dist/ and .vercel/output/
```
